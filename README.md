## About Me

I'm a **Software Engineer & Solution Architect** with 12+ years of experience (developing since 2014) building scalable, high-performance solutions end-to-end. I work primarily with **Flutter**, **Go**, **Svelte**, and **AI/LLM-based automation**, combining efficient backend architecture, modern interfaces, and intelligent process automation to transform ideas into working products.

### What I Work With

- Designing and deploying scalable multistack systems (mobile, backend, web)
- Building agentic AI systems and LLM-based automation pipelines
- Native cross-platform mobile apps with Flutter
- High-performance backend services and microservices in Go
- Modern, reactive web applications with Svelte
